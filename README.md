# Telco Customer Churn Prediction API

ML-модель для предсказания оттока клиентов телеком-компании с FastAPI и Docker.

## Возможности

- Предсказание оттока для одного клиента
- Пакетная обработка CSV файлов
- REST API интерфейс
- Docker контейнеризация
